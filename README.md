# COM731 - Urban Wildlife Interaction Analysis System

This project implements a Python-based software system for analysing urban wildlife interaction data. The application processes, analyses, and visualises data from a CSV dataset to support insights into wildlife behaviour, environmental conditions, and human–wildlife interactions in urban areas.

## Project Structure

- `main.ipynb` – Main program that controls execution flow and user interaction
- `csv_operations.py` – CSV-based data loading and retrieval (Task A)
- `data_analysis.py` – Data analysis using pandas (Task B)
- `data_visuals.py` – Data visualisation using matplotlib (Task C)
- `common_utils.py` – Shared utility functions (e.g., COM731 header printing)
- `Urban_wildlife.csv` – Dataset used for analysis

## Features

- CSV data processing using Python’s built-in `csv` module
- Analytical operations using pandas, including grouping and aggregation
- Visualisation of trends and patterns using matplotlib
- Menu-driven, text-based user interface
- Modular and maintainable project structure

## Requirements

- Python 3.10 or higher
- pandas
- matplotlib

## How to Run

1. Ensure all files are in the same directory.
2. Open `main.ipynb` using Jupyter Notebook.
3. Run the notebook and provide the CSV file path when prompted.
4. Use the menu options to execute CSV tasks, analysis tasks, or visualisations.
